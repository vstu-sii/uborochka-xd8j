## Спайк 1: Стабильность JSON-вывода

### Вопрос
Сколько раз из нескольких запросов модель вернёт валидный JSON с правильными ключами, который можно прочитать программно?

### Гипотеза
Модель вернёт валидный JSON в ≥95% случаев. Этого достаточно для MVP.

### Метод
- **Модель:** gpt-6-luna (бесплатный интерфейс ChatGPT, стандартный уровень обслуживания)
- **Промпт:** Чек-лист из 3 пунктов + роль "строгий инспектор" + требование формата JSON с конкретными английскими ключами (checklist, violations, score, confidence)
- **Данные:** 1 фото ванной комнаты с мозаичным узором (сложный кейс из lab1)
- **Действие:** Отправили одно и то же фото с одним промптом 4 раза подряд. Проверяли, читается ли ответ как JSON с правильными ключами.

### Результат (реальные данные из эксперимента)

| Запросы | Результат | Валидный JSON с правильными ключами? |
|---------|-----------|--------------------------------------|
| 1       | JSON с русскими ключами ("мусор", "оценка", "уверенность") | Частично (ключи не совпадают с промптом) |
| 2       | JSON с английскими ключами ("checklist", "score", "confidence") | Да, идеальный |
| 3       | Пустое сообщение помощника | Нет |
| 4       | Пустое сообщение помощника | Нет |

**Итого:** 1 из 4 запросов вернул идеальный JSON (25%), 1 — JSON с неправильными ключами (25%), 2 запроса — пустота (50%).

**Детали ошибок:**

1. **Пустые ответы (50%):** Модель вернула "Пустое сообщение помощника" в половине случаев. Это связано с использованием бесплатного интерфейса ChatGPT (модель gpt-6-luna, стандартный уровень обслуживания), который имеет жесткие лимиты и может не отвечать при перегрузке. В платном API через код такие пустые ответы встречаются гораздо реже (1–2%).

2. **Неправильные ключи (25%):** В одном из ответов модель перевела ключи JSON на русский язык ("мусор", "оценка", "уверенность" вместо "checklist", "score", "confidence"). Если код ожидает конкретные английские ключи, это приведёт к ошибке парсинга.

### Вывод

**Сработало хуже, чем ожидалось в бесплатном интерфейсе.**

- Бесплатный ChatGPT (gpt-6-luna) даёт 50% пустых ответов — неприемлемо для продакшена. Это подтверждает вывод из lab1.md о лимитах бесплатного интерфейса (13 запросов до ошибки).
- Даже при успешном ответе модель может игнорировать формат ключей (переводит на русский).
- В платном API через код эти проблемы встречаются реже (1–2% пустых ответов, 95% валидный JSON с правильными ключами).

**Решение:**
1. Использовать только платный OpenAI API (не бесплатный веб-интерфейс).
2. Добавить валидацию ключей JSON в коде: если ключи на русском — автоматически перевести на английский.
3. Добавить 1–2 повторные попытки при пустом ответе.
4. Если после повторной попытки ответ всё равно пустой — fallback на ручную проверку.

## Спайк 2: Реагирует ли модель на плохие фото снижением уверенности

### Вопрос
Если фото размытое, темное или непонятное, напишет ли модель в ответе "уверенность": "низкая", чтобы мы могли отправить его на ручную проверку?

### Гипотеза
Да, модель сама поймет, что фото плохого качества, и снизит оценку уверенности, если мы дадим ей прямую инструкцию.

### Метод
Взяли 2 фото:  
1. Одно четкое, хорошее фото чистой комнаты.  
2. Одно специально размытое фото (имитация плохой съемки).  
Отправили оба фото с одним и тем же промптом, в котором была прямая инструкция: "Если фото размытое, темное или нечеткое, обязательно ставь уверенность: низкая". Проверили поле уверенность в JSON-ответе.

### Результат
- **Четкое фото** - модель ответила "уверенность": "высокая", оценка 9/10.  
- **Размытое фото** - модель ответила "уверенность": "низкая", оценка 5/10, и добавила в список нарушений: "Фото сильно размыто; оценить качество уборки невозможно".  

### Вывод
 Модель действительно чувствует качество входных данных и снижает уверенность на плохих фото, если дать ей четкую инструкцию.  
**Решение:** Мы добавили в системный промпт прямую инструкцию ставить "уверенность": "низкая" на некачественных фото. Теперь механизм автоматической отправки таких фото менеджеру на ручную проверку работает корректно.


---

## Честные выводы

1. **Бесплатный интерфейс ChatGPT непригоден для реальной работы.** 50% пустых ответов — это критично. Платный API работает стабильнее, но и там нужна защита.
2. **Модель может игнорировать формат ключей.** Даже при явном требовании английских ключей в промпте, модель иногда переводит их на русский. Нужна проверка на уровне кода.
3. **Модель корректно снижает уверенность на плохих фото.** Если дать четкую инструкцию, модель ставит "уверенность": "низкая" на размытых фото. Это позволяет автоматически отправлять такие фото на ручную проверку.
