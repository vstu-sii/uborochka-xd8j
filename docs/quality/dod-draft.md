# Черновик DoD

## 1. DoD для артефакта "Golden Dataset"


|   | Критерий (Что проверяем)               | Тип проверки |  Целевое значение (Порог) | Статус |
|:--|:---------------------------------------| :--- | :--- |:-------|
| 1 | Файл датасета существует в репозитории | Есть/Нет | `true` (Exit code 0) |        |
| 2 | Минимальный объём ядра датасета        | Число | `>= 10` строк |        |
| 3 | Валидность формата JSONL               | Есть/Нет | `Exit code 0` (без ошибок парсинга) |        |
| 4 | Наличие обязательных ключей в JSON     | Есть/Нет | `100%` строк содержат все ключи |        |
| 5 | Физическое наличие изображений         | Есть/Нет | `100%` путей ведут к существующим файлам |        |
| 6 | Покрытие болей (обманные атаки)        | Число | `>= 1` пример |        |
| 7 | Покрытие болей (краевые случаи)        | Число | `>= 1` пример |        |


## 2. DoD для артефакта "Критерии успеха и метрики"

|   | Критерий (Что проверяем) | Тип проверки | Целевое значение (Порог)                  | Статус |
|:--| :--- | :--- | :--- |:-------|
| 1 | Документ существует и доступен | Ссылка | Файл есть, ссылка рабочая                 |        |
| 2 | Для каждой метрики есть формула | Есть/Нет | `100%` заполненных ячеек в колонке формул |        |
| 3 | Указаны целевые числовые значения | Число | `>= 5` метрик с числовыми значениями      |        |
