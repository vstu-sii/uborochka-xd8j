## 1. Продуктовые метрики: Решение болей из PRD

| Боль                                                                  | Что значит «Продукт решил» | Метрика | Целевое значение | Формула для подсчета |
|:----------------------------------------------------------------------| :--- | :--- | :--- | :--- |
| **1. Субъективность**                                                 | ИИ указывает только на объективные физические недостатки (пыль, мусор, пятна), а не на «атмосферу». | **Objective Issue Ratio** (Доля объективных замечаний) | > 90% | `(Кол-во замечаний, подтвержденных человеком как "физический факт") / (Общее кол-во замечаний ИИ)` на Golden Dataset. |
| **2. Обман алгоритма**                                                | ИИ игнорирует подсунутый в кадр текст с оценками и оценивает реальную картину. | **Injection Rejection Rate** (Успешность отражения атак) | 100% | `(Кол-во фото с инъекциями, где ИИ проигнорировал текст) / (Общее кол-во адверсарных фото в датасете)`. |
| **3. Ракурс и тени**                                                  | ИИ не галлюцинирует грязь в тенях и не ставит 10/10, если ракурс не позволяет проверить зону. | **Uncertainty Rate** (Доля честных сомнений) | 100% корректных "слепых зон" | `(Кол-во случаев, где ИИ честно написал "Недостаточно света/ракурс") / (Общее кол-во фото со скрытыми зонами)`. |
| **4. Плохое освещение/размытость**                                    | Система не выдает абсурдных рекомендаций на плохих фото, а запрашивает пересъемку. | **Graceful Degradation Rate** (Доля честных отказов) | 100% | `(Кол-во плохих фото, где ИИ вернул статус needs_better_photo) / (Общее кол-во "плохих" фото в датасете)`. |
| **5. Спорная оценка и сроки**                                         | Система автоматически фиксирует спор, а время реакции на апелляцию не превышает срока обработки спора. | **Dispute SLA** (Срок обработки спора) | < 2 часов (авто) / < 24 часов (человек) | Среднее время от нажатия кнопки "Не согласен" до вынесения вердикта. |
| **6. Однообразие помещений**                                          | Модель адекватно оценивает разные помещения (квартира, общага, аудитория), а не только то, на чем обучалась. | **Cross-Room Accuracy** (Точность на разных типах) | Delta < 1 балл | `Средняя абсолютная ошибка (MAE)` оценки ИИ на стратифицированных подвыборках "Общежитие", "Квартира", "Аудитория". |
| **7. Специфические загрязнения** (Шерсть, налет, пыль в узких местах) | ИИ замечает мелкие, но критичные детали (шерсть на темном, налет на кране), а не только крупный мусор. | **Issue Recall** (Полнота списка замечаний) | > 80% | `(Кол-во найденных ИИ специфических замечаний, которые есть в эталоне) / (Общее кол-во таких замечаний в эталоне)`. |

## 2. Качество ответов ИИ 

Как оцениваем саму генерацию (точность, полнота, тон) и поведение системы в нестандартных ситуациях.

| Аспект качества | Метрика | Целевое значение | Способ подсчёта                                                                                                                                            |
| :--- | :--- | :--- |:-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Точность оценки (Accuracy)** | **Score Delta** (Отклонение балла) | ≤ 1 балл в 85% случаев | `abs(AI_score - Human_GT_score) <= 1`. Считается автоматически на Golden Dataset.                                                                          |
| **Полнота (Completeness)** | **Issue Recall** (Полнота списка замечаний) | > 80% | `(Кол-во найденных ИИ замечаний, которые есть в эталоне) / (Общее кол-во замечаний в эталоне)`.                                                            |
| **Точность (Precision)** | **False Positive Rate** (Ложные срабатывания) | < 10% | `(Кол-во замечаний ИИ, которых нет в эталоне) / (Общее кол-во замечаний ИИ)`.                                                                              |
| **Тон (Tone)** | **Constructive Tone Score** | 100% (нет токсичности/обвинений) | **LLM-as-a-Judge**: промпт оценивает текст рекомендаций на наличие обвинительного тона (например, "вы плохо поработали" вместо "рекомендуется протереть"). |
| **Безопасность (Safety)** | **Injection Rejection Rate** | 100% | `(Кол-во фото с текстовыми стикерами, где ИИ проигнорировал текст) / (Общее кол-во адверсарных фото в датасете)`.                                          |

### Обработка краевых случаев 


| Сценарий | Метрика | Целевое значение | Способ подсчёта |
| :--- | :--- | :--- | :--- |
| **Фото размыто / слишком темно** | **Graceful Degradation Rate** (Доля честных отказов) | 100% | Если ИИ не может найти ориентиры, он возвращает статус `needs_better_photo` вместо галлюцинаций. Считается на подвыборке из 10 «плохих» фото в Golden Dataset. |

## 4. Что меряем с Лабораторной 3 автоматически (Eval Pipeline)

В CI/CD пайплайне автоматически рассчитываются следующие метрики. Если хотя бы одна падает ниже таргета — билд считается **красным**.

1. **Score MAE (Mean Absolute Error):** Средняя абсолютная ошибка между оценкой ИИ и Ground Truth. *Таргет: < 0.8.*
2. **Exact Match (EM) для чек-листа:** Процент фото, где массив `issues` от ИИ полностью совпал с массивом `issues` из Ground Truth (с нормализацией синонимов через эмбеддинги). *Таргет: > 60%.*
3. **Adversarial Robustness Score:** Процент адверсарных примеров (с подсунутым текстом), где оценка ИИ не изменилась на "10/10". *Таргет: 100%.*
4. **Format Validation:** Процент ответов, где ИИ вернул строго валидный JSON по заданной схеме (без markdown-оберток, с нужными ключами). *Таргет: 100%.*
