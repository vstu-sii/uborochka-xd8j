# DoD артефактов команды

Каждый критерий должен проверяться строго по одному из трёх типов:
1. **Есть/Нет** (файл существует, скрипт вернул `exit code 0`)
2. **Число** (количество строк >= 10, время выполнения < 5 сек)
3. **Ссылка** (в документе есть ссылка на другой артефакт)


## 1. DoD для артефакта "Success Criteria" 


|   | Критерий (Что проверяем) | Тип проверки | Целевое значение (Порог)            | Статус |
|:--| :--- | :--- |:------------------------------------|:---|
| 1 | Документ существует и доступен | Ссылка | Файл есть, ссылка рабочая           |        |
| 2 | Для каждой метрики есть формула | Есть/Нет | `100%` заполненных ячеек в колонке  |        |
| 3 | Указаны целевые числовые значения | Число | `>= 5` метрик с числовыми таргетами |        |


## 2. DoD для артефакта "Golden Dataset 1" 

|   | Критерий (Что проверяем) | Тип проверки | Целевое значение (Порог)        | Статус                   |
|:--| :--- | :--- |:--------------------------------|:-------------------------|
| 1 | Файл датасета существует | Есть/Нет | `true` (Exit code 0)            |                          |
| 2 | Минимальный объём датасета | Число | `>= 10` строк (в идеале 30-50)  |                          |
| 3 | Валидность формата JSONL | Есть/Нет | `Exit code 0` (без ошибок)      |                          |
| 4 | Наличие обязательных ключей | Есть/Нет | `100%` строк содержат все ключи |                          |
| 5 | Покрытие болей (Обманные атаки) | Число | `>= 1` пример                   |                          |
| 6 | Покрытие болей (Краевые случаи) | Число | `>= 1` пример                   |                          |
| 7 | Физическое наличие изображений | Есть/Нет | `100%` путей ведут к файлам     |                          |


## 3. DoD для артефакта "Eval Pipeline" (Скрипты автопроверки)

|   | Критерий (Что проверяем) | Тип проверки | Целевое значение (Порог)            | Статус |
|:--| :--- | :--- |:------------------------------------| :--- |
| 1 | Возможность запуска одной командой | Есть/Нет | `Exit code 0` (без фаталити ошибок) |  |
| 2 | Генерация отчёта о проверке | Есть/Нет | Файл существует, размер > 0 байт    |  |
| 3 | Отчёт содержит ключевые метрики | Есть/Нет | Ключи присутствуют в файле          |  |
