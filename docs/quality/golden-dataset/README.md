# Golden Dataset v2 - Эталонный набор данных

##  Описание

Этот датасет содержит **30 эталонных примеров** (пар «вход-эталон») для автоматической оценки качества работы ИИ-системы оценки уборки по фото.

Датасет покрывает все ключевые боли из PRD и проблемы, выявленные в baseline-отчёте Лабы 3.

## Процесс пополнения датасета

### Шаг 1: Идентификация пробела
Анализируем отчёт baseline (или предыдущего прогона). Находим метрики, которые не достигают таргета, и конкретные примеры, где модель ошиблась.

### Шаг 2: Сбор примеров
- **Реальные фото:** Снимаются в своих помещениях или помещениях знакомых с согласия владельцев
- **Яндекс Аренда:** Берём фото квартир из объявлений (без лиц и документов)
- **Интернет:** Фото с форумов клининга, Pinterest для специфических загрязнений
- **Синтетические модификации:** Создаются на основе чистых фото с помощью AI-инструментов

### Шаг 3: Разметка
Каждый пример размечается по формату из `golden-dataset-plan.md`:
- Уникальный ID
- Путь к изображению
- Эталонная оценка (ground_truth_score)
- Эталонный список замечаний (ground_truth_issues)
- Эталонные рекомендации (ground_truth_recommendations)
- Флаги: adversarial_flag, edge_case_flag
- Комментарий разметчика (labeler_comment)

### Шаг 4: Валидация
Скрипт `tests/evals/run_baseline.py` проверяет:
- Валидность JSON-формата
- Наличие всех обязательных ключей
- Существование файлов изображений

### Шаг 5: Коммит
Обновлённый файл `golden_v2.jsonl` коммитится в репозиторий. Сами изображения **не коммитятся** (хранятся локально в `data/images/raw/`), чтобы не нарушать авторские права.

## Проблемы baseline, которые закрывает v2

### Проблема 1: False Positive Rate = 44.44% (таргет 10%)
**Диагноз:** Модель выдумывает `dust` на чистых поверхностях с текстурой.
**Решение в v2:** Добавлены 5 примеров чистых поверхностей с выраженной текстурой:
- `gd_011`: Деревянная столешница (текстура дерева)
- `gd_012`: Ковёр с длинным ворсом
- `gd_013`: Тканевая обивка дивана
- `gd_014`: Мраморная столешница (прожилки)
- `gd_015`: Обои с рисунком

**Ожидаемый эффект:** Модель научится различать текстуру и грязь → FP Rate снизится.

### Проблема 2: Graceful Degradation = 50% (таргет 100%)
**Диагноз:** На тёмных фото модель галлюцинирует вместо отказа.
**Решение в v2:** Добавлены 4 новых краевых случая:
- `gd_016`: Очень тёмное фото (почти чёрное)
- `gd_017`: Размытое фото
- `gd_018`: Засвет от вспышки
- `gd_019`: Неправильный баланс белого (синий оттенок)

**Ожидаемый эффект:** Модель научится возвращать `needs_better_photo` → Graceful Degradation Rate вырастет до 100%.

### Проблема 3: Нужно больше адверсарных примеров
**Диагноз:** Всего 2 примера инъекций — недостаточно для robustness.
**Решение в v2:** Добавлены 4 новых адверсарных примера:
- `gd_020`: Стикеры на зеркале
- `gd_021`: Надпись маркером на стене
- `gd_022`: Экран телефона с текстом
- `gd_023`: QR-код на столе

**Ожидаемый эффект:** Модель станет устойчивее к разным видам инъекций.

### Проблема 4: Разнообразие помещений
**Диагноз:** Всего 4 типа помещений — модель может переобучиться.
**Решение в v2:** Добавлены 6 новых типов помещений:
- Санузел, балкон, прихожая, детская, гардеробная, столовая

**Ожидаемый эффект:** Улучшится Cross-Room Accuracy (Delta < 1 балл между типами).
