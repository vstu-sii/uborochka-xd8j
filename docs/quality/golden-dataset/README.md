# Golden Dataset 1

Датасет содержит пары «вход-эталон» для автоматической оценки качества работы ИИ-системы оценки уборки по фото.

Датасет покрывает все ключевые боли из PRD:
- Субъективность
- Обман алгоритма (адверсарные атаки)
- Краевые случаи (плохое освещение, скрытые зоны)
- Специфические загрязнения (шерсть, налёт, пыль)
- Разные типы помещений (квартиры, общежития, аудитории)

## Владелец датасета

**Quality Lead:** (Я)/Клининговая компания

Только владелец имеет право добавлять или изменять разметку (Ground Truth). Все изменения фиксируются через Pull Request с описанием причины.

## Процесс пополнения датасета

1) Если метрики из `success-criteria.md` показывают, что модель плохо справляется с определённым типом кейсов (например, не замечает шерсть на тёмной мебели), владелец фиксирует это как пробел в датасете.
2) Сбор примеров:
- **Реальные фото:** Снимаются в Катиной квартире или помещениях знакомых с согласия владельцев(по желанию), а также берутся с яндекс аренды.
- **Синтетические модификации:** Создаются на основе чистых фото из Яндекс Аренды с помощью AI-инструментов (В основном гигачатом)
- **Адверсарные примеры:** Создаются вручную (например, фото с бумажкой "10/10" на грязном столе)

3) Разметка: 

Каждый пример размечается по формату из `format-spec.md`:
- Уникальный ID
- Путь к изображению
- Эталонная оценка (ground_truth_score)
- Эталонный список замечаний (ground_truth_issues)
- Эталонные рекомендации (ground_truth_recommendations)
- Флаги: adversarial_flag, edge_case_flag
- Комментарий разметчика (labeler_comment)

4) Валидация:

Скрипт `scripts/validate_jsonl.py` проверяет:
- Валидность JSON-формата
- Наличие всех обязательных ключей
- Существование файлов изображений

5) Коммит:

Обновлённый файл `golden_v1.jsonl` коммитится в репозиторий. Сами изображения не коммитятся (хранятся локально в `data/images/`), чтобы не нарушать авторские права.
