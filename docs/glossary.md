# Часть 4. Глоссарий команды

**Цель:** использовать одинаковые термины при обсуждении продукта, датасета, промптов и результатов модели.

| Термин | Определение |
| --- | --- |
| **Качество уборки** | Итоговая характеристика состояния помещения по видимым на фотографии признакам чистоты и порядка. |
| **Чистота** | Отсутствие видимых загрязнений: пыли, мусора, разводов, налёта, шерсти и других следов. |
| **Порядок** | Степень организованности пространства; например, отсутствие разбросанных вещей при чистом полу. |
| **Непроверенная зона** | Часть помещения, состояние которой невозможно достоверно оценить из-за ракурса, мебели, предметов или освещения. |
| **Визуальное замечание** | Конкретный наблюдаемый признак, ухудшающий результат: например, разводы на зеркале. |
| **Ракурс** | Положение камеры относительно помещения и объектов в кадре. |
| **Недостаточное освещение** | Условие, при котором детали поверхности или части помещения плохо различимы. |
| **Computer Vision** | Методы ИИ для анализа изображений и выделения визуальных признаков. |
| **Мультимодальная модель** | Модель, способная обрабатывать более одного типа данных, например текст и изображение. |
| **Структурированный промпт** | Инструкция модели с заданными критериями и форматом ответа. |
| **Telegram-бот** | Интерфейс продукта, через который пользователь отправляет фотографию и получает результат анализа. |
| **Оценка 1–10** | Числовое представление результата проверки качества фотографии. |
| **Доказательство** | Наблюдаемый на изображении признак, на котором основано замечание или часть оценки. |
| **Golden dataset** | Набор эталонных примеров изображений с заранее определёнными правильными ответами для проверки модели. |
| **Тестовый кейс** | Конкретная ситуация или фотография, на которой проверяется работа системы. |
| **Гипотеза** | Проверяемое предположение о пользователе, проблеме или продукте. |
| **Фальсифицируемая гипотеза** | Гипотеза, для которой заранее определено наблюдение, способное её опровергнуть. |
| **MVP** | Минимальная версия продукта с набором функций, достаточным для проверки ключевой ценности. |
| **North Star** | Главный результат, отражающий создаваемую продуктом ценность для пользователя. |
| **Сегмент** | Узкая группа пользователей с общей задачей и похожими потребностями. |
| **Приёмщик** | Человек, который принимает результат клининговых работ и фиксирует замечания. |
| **Управляющий объектом** | Человек, отвечающий за состояние и обслуживание объекта недвижимости. |
| **Ложное обвинение** | Ситуация, когда система объявляет участок грязным, хотя по фотографии это нельзя надёжно подтвердить. |
| **Воспроизводимость оценки** | Способность получать сопоставимый результат при похожих условиях проверки. |
| **Итоговый бриф** | Краткое описание того, какую проблему решает продукт, для кого, как работает и каким должен быть результат. |
