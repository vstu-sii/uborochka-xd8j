# ADR-0001: Деградация провайдера модели по пользовательскому бюджету

## Статус

Принято.

## Контекст

Основной vision-провайдер может быть недоступен или расходовать дневной
лимит. Система должна предсказуемо ограничивать расходы, не отдавать модели
права на запись и продолжать выдавать ограниченную оценку, когда primary
недоступен или достигнут порог деградации.

## Решение

- Контракт `ModelProvider.analyze(photo) -> CleaningAssessment` расположен в
  `backend/providers.py`.
- Gemini Flash-Lite (`gemini-2.5-flash-lite`) — опциональный primary:
  активируется только при `GEMINI_ENABLED=true` и наличии
  `GEMINI_API_KEY`.
- Fallback по умолчанию — локальная baseline-эвристика (Pillow),
  `baseline-heuristic-v1`. Она также используется, если Gemini недоступен.
- Счётчики запросов и токенов хранятся отдельно по пользователю и календарной
  дате в PostgreSQL. При достижении 80% `DAILY_TOKEN_LIMIT` запрос
  автоматически идёт через fallback и получает `degraded=true`.
- Превышение `DAILY_REQUEST_LIMIT`, `DAILY_TOKEN_LIMIT` или
  `MONTHLY_BUDGET_USD` блокирует запрос с HTTP 429 и русским сообщением.
- Для базовой эвристики входные токены оцениваются как один токен на четыре
  байта изображения. Месячная стоимость — приближение по ставке
  `0.10 USD / 1M` токенов; это не биллинг-показатель провайдера.
- Состояние `degraded`, имя провайдера/модели, латентность и число токенов
  передаются в ответ, JSON-событие, Prometheus и `llm.call` span.

## Последствия

- Порог и лимиты конфигурируются через `DAILY_REQUEST_LIMIT`,
  `DAILY_TOKEN_LIMIT`, `MONTHLY_BUDGET_USD`; нет зависимости от
  нестабильного in-memory состояния.
- Без Gemini приложение всё равно работает на baseline-эвристике; результат
  ограничен простой оценкой яркости/детализации фото и не является
  профессиональной приёмкой качества.
- Чтобы включить Gemini, нужен секрет `GEMINI_API_KEY` в окружении и явное
  `GEMINI_ENABLED=true`; в CI используются моки, сетевые вызовы не нужны.
- При недоступной БД лимиты проверить нельзя, поэтому запрос не выполняется
  (503), а не пропускается без ограничений.
